# Learnings

Short lessons from past sessions, shown at the start of every session by
`.claude/hooks/session-start.sh`. A session adds a line when the owner corrects it or
when it catches its own mistake (see `/wrap-session`). One line each, dated, most
recent first. Keep the file under about 40 lines: merge duplicates, and when a lesson
is a rule that a test could check, propose the test (see `src/conventions.test.ts`)
and remove the line once the test is merged.
